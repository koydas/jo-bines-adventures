# Joe Bines Adventures
Adventures of a boy that go against skeletons

see itch.io: https://koydas.itch.io/les-aventures-du-bonhomme-bizarre

### Features
- Can buy in shop
- Can fight monsters
- Can use potions
- Can travel

## Two versions in this repo

- **`platformer/`** — the original GameMaker Studio 2 project.
- **`web/`** — a modern TypeScript + Phaser 3 port, built to be played
  straight from a browser (including iPhone Safari, with touch controls and
  "Add to Home Screen" support) and to be easy to keep developing on with
  Claude Code, without needing GameMaker Studio installed. See
  [`web/README.md`](web/README.md) for how to run, build, and deploy it
  (Docker included) on your own server.
